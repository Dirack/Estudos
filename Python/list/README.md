Resumo para decorar
Operação	Exemplo
Criar	lista = [1,2,3]
Acessar	lista[0]
Último elemento	lista[-1]
Adicionar	lista.append(x)
Inserir	lista.insert(i,x)
Remover valor	lista.remove(x)
Remover índice	lista.pop(i)
Tamanho	len(lista)
Percorrer	for item in lista
Slicing	lista[1:4]
Do início	lista[:3]
Até o fim	lista[2:]
Passo	lista[::2]
Inverter	lista[::-1]
